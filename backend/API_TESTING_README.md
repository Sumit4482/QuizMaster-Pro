## 🐛 Common Issues & Solutions

### ❌ Server Not Running
**Error:** `Cannot connect to API server`
**Solution:** 
```bash
npm start
```

### ❌ Database Not Ready
**Error:** `Database operation failed`
**Solution:**
```bash
npm run db:reset
npm run db:seed
```

### ❌ Authentication Failures
**Error:** `UNAUTHORIZED` or `TOKEN_EXPIRED`
**Solution:** Tests handle token refresh automatically, but check admin user exists:
```bash
# Check if admin user exists
npm run db:studio
```

## 📝 Adding New Tests

### 1. Basic Test Structure
```javascript
await this.runTest(
  'Category',           // Test category
  'Test Name',          // Test name
  'Test description',   // Description
  async () => {         // Test function
    const response = await this.api.get('/api/endpoint');
    return {
      statusCode: response.status,
      // ... other details
    };
  },
  [200, 201]           // Expected status codes
);
```

### 2. Error Test Structure
```javascript
await this.runTest(
  'Error Handling',
  'Invalid Request',
  'Test invalid input handling',
  async () => {
    try {
      await this.api.post('/api/endpoint', invalidData);
      throw new Error('Should have failed');
    } catch (error) {
      if (error.response?.status === 400) {
        return {
          statusCode: error.response.status,
          correctlyRejected: true
        };
      }
      throw error;
    }
  },
  [400]
);
```

## 📚 API Endpoints Summary

### Public Endpoints (No Auth Required)
- `GET /health/ready` - Health check
- `GET /health/live` - Liveness check
- `GET /api-docs` - Swagger documentation
- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `POST /api/auth/refresh` - Token refresh

### Protected Endpoints (Auth Required)
- `GET /api/auth/profile` - User profile
- `PUT /api/auth/profile` - Update profile
- `GET /api/categories` - List categories
- `GET /api/categories/tree` - Category hierarchy
- `GET /api/questions/search` - Search questions
- `POST /api/quiz/sessions` - Create quiz session
- `POST /api/quiz/sessions/:id/start` - Start quiz
- `GET /api/quiz/sessions/:id/current-question` - Get current question
- `POST /api/quiz/sessions/:id/submit-answer` - Submit answer
